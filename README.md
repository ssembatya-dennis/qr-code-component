## My process

- I began by analyzing the image design and carefully understanding the layout structure of the card component and the suitable semantics to utilize while building the card

- After downloading the starter files I quickly used the AI tool to teach me deploy using Github pages as I have never deployed any component before using this option

- I wrote my HTML structure for the page, connected my stylesheet and began styling the card

- I occasionally inquired from the LLM tool to remind a few properties that I had forgotten off head and by styling element by element I managed to complete my card and pushed my code on Github
